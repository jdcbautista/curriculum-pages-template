# Curriculum Template

A curriculum website made only of Markdown files. GitHub Pages serves it as-is: there is no build step, no package install and no workflow to maintain.

**Use it:** click **Use this template** on [the GitHub repository](https://github.com/jdcbautista/curriculum-pages-template), then follow [How to build, run and maintain](README.md).

## What you get

- A landing page (this file, `home.md`)
- A sidebar built from `_sidebar.md`
- Lessons as plain Markdown files in `lessons/`
- Search across every page and Previous / Next links between lessons
- Collapsible answer keys using `<details>`
